# Wireframes Reflection

## Desktop vs. Phone Layouts

The desktop version has more space, so I can show more UI elements at the same time. The phone version has less space, so I made the buttons larger and kept the screen less crowded.

## UI/HUD Changes

I moved the controls to the bottom of the phone screen so they are easier to reach with a thumb. I also hid some extra information, such as the map and inventory, behind menus. The health bar and important objectives stayed visible because players need to see them while playing.

## Designing for Real Screen Sizes

I noticed that UI elements that look fine on a large screen can take up too much space on a phone. Designing for actual screen sizes helped me think about button size, spacing, and how much information the player really needs.

## Player Experience

The desktop version gives players more information and makes it easier to see the game world and HUD. The phone version is simpler and focuses on easy touch controls, making it easier to play on a smaller screen.
