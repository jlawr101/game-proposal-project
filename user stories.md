User Story 1  
As a new player, I want to beat the game, so that I can win.

Acceptance Criteria 1: The player can beat the final boss.  
Acceptance Criteria 2: The game shows the credits page.

User Story 2  
As a returning player, I want to have fun, so that I can have a good day.

Acceptance Criteria 1: The player can appreciate the scenery.  
Acceptance Criteria 2: The game shows good visuals.

User Story 3  
As a pro/speedrunner,I want to get the fastest time , so that I can upload my fastest time online and be famous.

Acceptance Criteria 1: The player can beat the game fast.  
Acceptance Criteria 2: The game shows the player is at the top of the leaderboard.
